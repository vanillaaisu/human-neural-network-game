# AI Icebreaker Games

**Human Neural Network** is a no-dependency, browser-based facilitator guide for a 10–15 minute drawing-and-description relay. Teams pass a secret scene along a line, alternating between describing and drawing, then compare the final guess with the original.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server, for example:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`. The facilitator controls include a 12-minute timer, a set of secret scene prompts, adjustable team sizes, and a round-two shuffle flow. Use paper and pens for the relay itself.
